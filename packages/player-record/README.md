# Player Record Package

## Purpose

This package defines score, mastery, history, completion, replay, and campaign legacy.

The system gives the player clear performance feedback without reducing human choices to one morality score.

## Stable rules

- Score observable craft, not belief or personal worth.
- Preserve the Canon Mark when the player improves a Best Mark through replay.
- Record competing accounts without inventing omniscient certainty.
- Let mastery unlock verbs, information, reliability, and shared actions.
- Keep accessibility independent from difficulty and score.
- Preserve each completed run through an immutable Legacy Card.
