# Trailer and Gameplay Animatic Package

## Purpose

Defines the shot plan, timed sequences, scratch dialogue, sound cues, interface overlays, and production gates.

## Canonical design sources

- `Beyond_the_Ridge_Trailer_Gameplay_Animatic_Production_Bible_v1.pptx`
- `Beyond_the_Ridge_Animatic_Cuebook_v1.xlsx`

## Review export

`Beyond_the_Ridge_Trailer_Gameplay_Animatic_Production_Bible_v1.pdf`

## Repository mirror

The cuebook is available as diffable CSV files:

- `trailer-shots.csv`
- `gameplay-sequences.csv`
- `dialogue-and-vo.csv`
- `sound-cues.csv`
- `ui-overlays.csv`

The source deck, cuebook workbook, and PDF remain outside Git history.

## Change rule

Keep timecodes, dialogue, sound, interface, and source anchors synchronized before an animatic export.
