# Persistence System Package

## Purpose

This package defines Redemption Windows and Second Roads after selected losses.

The system preserves the original consequence and starts recovery inside the changed world state.

## Stable rule

A Second Road offers another form of agency.

It does not erase the loss, identify itself as the true ending, or require unsafe reconciliation.
