## Purpose

Defines the core loop, repair, care, traversal, dialogue, evidence, relationships, progression, failure, and accessibility.

## Stable system contract

```text
Observe -> Work or Explore -> Disruption -> Choice -> Result -> Return Home -> Reconsider
```

The interface does not expose an unknown future consequence.
