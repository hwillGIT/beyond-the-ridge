# Game-Design Card Library

## Purpose

The card library turns large design bibles into small production references.

Each card answers one question quickly.

The library supports writers, artists, level designers, sound designers, reviewers, and future prototype developers.

## Card families

- 13 character cards.
- 15 location cards.
- 10 system cards.
- 8 encounter cards.
- 5 worldview cards.
- 6 relationship-state cards.
- 12 gameplay-keyframe cards.

The complete library contains 69 cards.

## Stable card fields

Each card has:

- A unique identifier.
- A family.
- A title.
- A short design statement.
- A gameplay hook.
- A pressure or trade-off.
- A canonical anchor.
- A visual asset when one exists.

## Visual rule

A rendered card uses one dominant image and no more than five short text blocks.

The image must communicate the card before the reader studies the text.

Do not use decorative icons when a real object, face, tool, route, or place can carry the meaning.

## Canon rule

The card library summarizes canon. It does not create canon by itself.

Use the World Bible, Character Bible, Gameplay Systems Bible, accepted decision records, and source register when a conflict appears.

## Youth review rule

A card should be understandable in less than 20 seconds.

If a card needs a paragraph of explanation, split the idea or simplify the design.
