# Player Record UI Proof Set

These PNG files show the player-facing Living Record and Roadbook systems.

## Files

- `00-player-record-ui-overview.png` shows the complete six-screen set.
- `01-encounter-scorecard.png` separates craft score from practical outcome.
- `02-mastery-roadbook.png` shows capability tiers and mastery proofs.
- `03-living-history-entry.png` shows competing accounts and causal history.
- `04-challenge-board.png` separates Canon Marks from replay Best Marks.
- `05-journey-score.png` shows the optional act-level score.
- `06-legacy-card.png` summarizes one completed playthrough.

These images are previsualization targets. They do not represent an engine build.

Canonical rules remain in `docs/design/PLAYER_RECORD_MASTERY_HISTORY_AND_LEGACY_BIBLE.md`.
