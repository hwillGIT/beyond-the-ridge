# Educated chapter poster reference set

This directory contains one PNG poster for each of the 40 numbered chapters of Tara Westover's *Educated*.

The posters are project-generated visual study references. They support literary analysis and the design provenance for *Beyond the Ridge*.

The source memoir is not stored in this repository.

## File order

Files use the two-digit chapter number followed by the canonical chapter title.

## Known artwork note

Chapter 24 uses the original project poster artwork. The image contains the legacy working title `Pa-Shun`.

The canonical chapter title is **A Knight, Errant**. The repository filename uses the canonical title.

Do not treat the legacy title inside that image as source evidence.
