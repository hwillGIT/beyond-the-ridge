# Motion Studies

These PNG boards test six player actions before engine implementation.

- `00-mara-vale-character-reference.png` is the current visual continuity anchor for Mara.
- `01-axle-inspection.png` tests inspection and diagnosis.
- `02-emergency-stop.png` tests readable machinery danger and interruption.
- `03-drive-and-talk.png` tests simultaneous driving, observation, and conversation.
- `04-cedar-gate-navigation.png` tests landmark-based town navigation.
- `05-evidence-journal.png` tests analog evidence revision.
- `06-college-threshold.png` tests learning unfamiliar institutional rules.

See `docs/production/MOTION_STUDY_SPECS.md` for timing, interaction, and review requirements.

These are previsualization studies. They do not represent an engine build.
