# Assets

## Purpose

This directory contains preview images and transformed visual references.

## Directories

- `previews/` contains repository navigation images.
- `reference-posters/` contains generated classroom posters used for mood and thematic review.

## Asset rule

A preview is not a canonical design source.

Use the editable deck, spreadsheet, or source document for a design change.

## Rights rule

Do not add publisher cover art or scanned book pages.

Label a direct source image as restricted and keep it outside a public repository.
