# Contextual Gameplay UI Frames

These PNG frames show interface behavior during social, traversal, town, and return-home scenes.

1. `02-breakfast-pressure-context-ui.png` shows live conversation intent during a family meal.
2. `06-county-road-context-ui.png` shows driving, route, weather, fuel, rumor, and mobile-dialogue information.
3. `07-cedar-gate-context-ui.png` shows exploration prompts, town activity, parts objectives, and rumor collection.
4. `08-supper-version-context-ui.png` shows the return-home consequence choice and relationship-state feedback.

These images are previsualization targets. They do not represent an engine build.
