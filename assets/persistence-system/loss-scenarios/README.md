# Loss-Scenario Concept Frames

These images prove that the game can show failure before, during, and after the decisive action.

Each frame should communicate:

- the immediate objective,
- the readable threat,
- the available response,
- the possible defeat,
- the persistent consequence,
- and any hidden Redemption Seed.

The images are previsualization targets. They do not represent an engine build.

Generated HUD wording is not canonical. Use the design specifications for implementation copy.
