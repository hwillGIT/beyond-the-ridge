# Persistence System Visuals

These PNG files support the Redemption Windows and Second Roads design.

## Bibles

The `bibles/` directory contains three visual explanations of the Persistence System.

- `00-primary-persistence-system-bible.png` is the primary visual summary.
- `01-detailed-persistence-system-bible.png` is the portrait reference board.
- `02-two-page-persistence-system-bible.png` is the landscape reference board.

## Review images

The `reviews/` directory contains slide and PDF review montages.

## Loss scenarios

The `loss-scenarios/` directory contains four gameplay concept frames:

1. Engine-load imbalance.
2. Rain-road crash.
3. Ridge exposure.
4. Wrong-accusation consequence.

These frames establish action, risk, persistent loss, and possible Redemption Seeds.

Generated interface text is exploratory. It does not override the canonical control, HUD, loss, or Persistence System documents.

See `docs/design/REDEMPTION_WINDOWS_AND_SECOND_ROADS_BIBLE.md` and `source/redemption-window-ledger.csv`.
