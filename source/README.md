# Source Register

## Purpose

This directory records source relationships without storing protected source copies.

## Primary source

Tara Westover, *Educated: A Memoir*. Random House, 2018.

## Storage rule

Do not commit the uploaded book PDF.

Do not commit an audiobook, page scan, or long quotation.

Use chapter references and concise detail notes.

## Register fields

The source register records:

- Source identifier.
- Chapter or section.
- Detail category.
- Concise source note.
- Game transformation.
- Rights class.
- Review state.
