# Rights and Use

## Project status

**Beyond the Ridge** is a classroom concept exercise with a provisional title.

The project is not an authorized adaptation of Tara Westover's *Educated*.

## Source rights

Tara Westover and the applicable rights holders retain all rights in *Educated*.

The public repository must not contain:

- The full book text.
- An audiobook copy.
- Publisher cover art.
- Long quoted passages.
- Scans or photographs of protected pages.
- Unlicensed music, film, or theater recordings.

The source register can record short citations, chapter references, and concise notes.

## Project-original material

Project-original material includes fictional names, character biographies, mechanics, mission structures, interface concepts, and original dialogue.

A source note must identify material that uses a direct detail from the memoir.

## Transformation rule

Each source-derived element must pass three tests:

1. The element serves a new gameplay purpose.
2. The element does not recreate the memoir scene as spectacle.
3. The element preserves the source's human complexity.

## Commercial use

Do not use this repository for commercial production before legal review.

A commercial project can require adaptation rights, title clearance, likeness review, trademark review, and location review.

## Sensitive material

Do not reward the player for tolerating abuse.

Do not require repeated traumatic actions for progression.

Do not use family violence, medical danger, or religious conflict as decorative shock.

The player can use a content option without losing access to the story.

## Public repository boundary

This repository is public and contains only approved project material and concise source records.

Keep restricted research material, protected source copies, and unreleased rights-sensitive assets outside this repository.

A future visibility change does not remove the source-rights rules.
