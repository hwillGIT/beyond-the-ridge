# Capability Status

## Purpose

This page states what the project defines and what the repository proves.

## Defined capabilities

The project defines:

- world regions, routes, tasks, and environmental rules,
- characters, worldviews, strengths, blind spots, and relationship arcs,
- art, sound, interface, and accessibility targets,
- a transformed chapter-to-game matrix for all 40 memoir chapters,
- a core gameplay loop,
- a 28-panel opening storyboard,
- dialogue, forms of address, memory triggers, and place details,
- a controller and keyboard contract,
- gameplay feedback and interface rules,
- meaningful loss and optional permadeath,
- the Persistence System,
- 24 Redemption Windows,
- a layered Player Record,
- Living History,
- a Challenge Board,
- an optional Journey Score,
- a Legacy Card,
- a 69-card design library,
- a 90-second trailer specification,
- a three-minute gameplay-preview specification,
- and a youth engagement target loop.
