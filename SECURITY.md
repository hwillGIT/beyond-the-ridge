# Security and Privacy

## Supported material

This repository contains design documents and media assets. It does not contain production services or player data.

## Do not commit

Do not commit:

- Credentials or access tokens.
- Private contact information.
- Unreleased contracts.
- Protected source copies.
- Student records.
- Medical records.
- Interview recordings without consent.
- Personal journal text from test participants.

## Reporting

Report a security or privacy concern to the repository owner through a private channel.

Do not open a public issue that exposes credentials, private records, or protected source files.

## Prototype requirements

A future prototype must separate player saves from research notes.

A future shared-story feature must not upload private journal text.

The feature can share decision maps only after the player gives clear consent.
