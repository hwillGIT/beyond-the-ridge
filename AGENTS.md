# Agent Instructions

## Mission

Preserve the project as an original game concept with a clear relationship to *Educated*.

Do not turn the project into a direct retelling.

## Required reading

Read these files before a repository-wide change:

- `README.md`
- `RIGHTS_AND_USE.md`
- `docs/fidelity/README.md`
- `docs/WRITING_STANDARD.md`
- `docs/GLOSSARY.md`

Read the relevant package README before you edit an artifact.

## Canon rules

Use Mara Vale as the player character.

Use the canonical character names in the Character Bible.

Use the canonical place names in the Location Bible.

Do not restore superseded working names.

Record a canon change in an architecture decision record.

## Source rules

Use the source register for book-informed details.

Distinguish a direct fact from an original transformation.

Do not invent a source citation.

Do not store the full memoir in this repository.

Do not imitate Tara Westover's prose voice.

## Narrative rules

Write original dialogue.

Use book-informed subjects, rhythms, forms of address, and memory triggers.

Keep affection, danger, humor, faith, competence, and contradiction in the same human world.

Do not make a character a simple symbol for a social group.

## Game-design rules

Every major encounter must support at least three valid approaches.

Every practical task must affect a relationship, access state, evidence state, or future choice.

The interface must not reveal an unknown future consequence.

The game must not use a single morality score.

## Content-care rules

Do not reward endurance of abuse.

Do not require traumatic repetition for mastery.

Preserve content options without a story penalty.

Request review for violence, medical danger, coercive control, and religious conflict.

## Writing rules

Apply the `write-timeless-technical-prose` skill from `hwillGIT/library-of-context`.

Write the system in one editorial present.

State components, conditions, actions, and effects directly.

Do not narrate the prompt, authoring process, or edit sequence.

Do not claim formal ASD-STE100 compliance.
