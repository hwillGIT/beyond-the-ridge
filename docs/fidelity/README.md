# Source and Fidelity Guide

## Purpose

This guide keeps the project recognizable, original, and responsible.

## Source method

Use four steps for each book-informed element:

1. Identify the source detail or tension.
2. State why the detail matters in the memoir.
3. Transform the detail into an original game function.
4. State the ethical or narrative guardrail.

## Detail layers

### Environmental details

Examples include mountain weather, the red railway car, salvage work, herb rooms, small-town roads, and college architecture.

### Social details

Examples include pet names, family jokes, work commands, meal routines, church speech, and town reputation.

### Memory details

Examples include conflicting recollections, repeated family stories, sensory triggers, and a revised understanding of an old event.

### Institutional details

Examples include a courthouse, clinic, registrar, library, engineering building, meetinghouse, lecture hall, and college dining hall.

## Dialogue rule

Write original dialogue.

Use the source to inform vocabulary, rhythm, address, subject matter, silence, and social pressure.

Do not copy a distinctive passage or reproduce a memoir scene line by line.

## Place rule

A named place can serve one of three functions:

- A direct reference in a classroom concept.
- A transformed place in the fictional game world.
- A research note that never appears in the game.

The location bible identifies the selected function.

## Memory rule

The journal separates three states:

- **Saw:** What Mara directly observed.
- **Heard:** What another person claimed.
- **Concluded:** What Mara believes the evidence supports.

A later revision retains the earlier conclusion as a trace.

## Review questions

- Does the detail serve gameplay or character understanding?
- Does the detail preserve human complexity?
- Does the scene avoid spectacle and caricature?
- Does the project identify the source relationship?
- Does the transformation create a new dramatic function?
