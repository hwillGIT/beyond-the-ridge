# ADR-0008: Persistence System and hidden Second Roads

## Status

Accepted

## Context

The game allows persistent defeat, dark endings, and optional campaign loss.

Loss must remain credible.

The project also wants selected endings to preserve a final possibility for agency, repair, transformation, or legacy.

An obvious retry prompt would weaken the loss.

A fully hidden continuation could become inaccessible or feel arbitrary.

## Decision

Use a Persistence System with selected Redemption Windows.

A Redemption Window keeps limited player control during a complete losing ending.

A previously foreshadowed person, object, place, record, capability, or act of grace can become a Redemption Seed.

The default activation uses dwell focus for 15 seconds.

The player receives ordinary world cues before one contextual action appears.

Activating the seed starts a Second Road in the saved loss state.

The original consequence remains canon.

The Second Road requires a meaningful recovery cost and can fail.

Not every losing ending receives a window.

Accessibility settings can strengthen cues and shorten dwell time without exposing a redemption marker.

## Consequences

The narrative team must foreshadow every seed.

The state model must preserve injuries, deaths, records, debt, lost assets, bans, and relationships across the Second Road.

The save system must branch the continued path without deleting the Apparent Ending.

The UI cannot use a redemption meter, glow, rarity frame, or hidden true-ending label.

The content-care review must reject any path that requires unsafe reconciliation or rewards harmful endurance.

Iron Ridge death can use a Legacy Chapter, but Mara remains dead.
