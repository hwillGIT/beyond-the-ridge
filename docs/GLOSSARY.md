# Glossary

**Capability:** A skill, access state, or understanding that changes available player actions.

**Canonical artifact:** The approved source file for one design area.

**Clarity:** A relationship state that describes how accurately two characters understand each other.

**Consequence hub:** A home scene that reflects choices made elsewhere in the world.

**Direct fact:** A specific detail recorded in the memoir or another cited source.

**Evidence state:** The set of observations, claims, records, and conclusions available to the player.

**Insight:** Player knowledge about a character's values, fears, habits, or contradictions.

**Memory journal:** A record with separate Saw, Heard, and Concluded fields.

**Original transformation:** A new game element that uses a source tension for a different function.

**Source register:** The repository record that identifies source relationships and restrictions.

**Vertical slice:** A short, representative section that tests the main systems and production quality.

**Worldview profile:** A structured description of the values that guide one character's interpretation.
