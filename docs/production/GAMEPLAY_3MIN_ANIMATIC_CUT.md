# Three-Minute Gameplay Animatic Cut

## Purpose

This cut tests whether the project reads as a game when the pace slows down.

It uses the 12 approved gameplay keyframes as a reviewable prototype sequence.

The cut is not engine footage.

## Review structure

Each keyframe holds for 15 seconds.

The reviewer should use the hold time to identify the likely player verb, pressure, alternative action, and consequence.

| Time | Frame | Player verb | Pressure | Review question |
|---|---|---|---|---|
| 0:00-0:15 | Ridge Dawn | Observe / choose route | Workday begins | Does the world invite movement? |
| 0:15-0:30 | Breakfast Pressure | Listen / answer / conceal | Family expectation | Does conversation feel like gameplay? |
| 0:30-0:45 | Hairline Crack | Inspect / diagnose | Abel wants speed | Is competence readable? |
| 0:45-1:00 | Suspended Load | Stop / stabilize / call | Immediate danger | Are alternatives spatially legible? |
| 1:00-1:15 | Mercy House | Treat / question / escalate | Care under uncertainty | Does the game avoid a fake perfect answer? |
| 1:15-1:30 | County Road | Drive / observe / talk | Social exposure | Does travel remain active? |
| 1:30-1:45 | Cedar Gate | Explore / ask / work | Family reputation | Does the town feel learnable by sight? |
| 1:45-2:00 | Supper Version | Correct / deflect / remain silent | Family story changes | Does social consequence feel tangible? |
| 2:00-2:15 | Memory Journal | Sort evidence / revise | Conflicting accounts | Is interpretation a player action? |
| 2:15-2:30 | Ridge Signal | Prepare / investigate / retreat | Weather and secrecy | Does curiosity create risk? |
| 2:30-2:45 | College Threshold | Navigate / ask / infer | Unknown rules | Can failure teach without humiliation? |
| 2:45-3:00 | Wider World | Explore / connect / remember | Identity expands | Does expansion preserve attachment to home? |

## Player-loop test

The preview should make this loop visible without a narrator:

`Notice -> Choose -> Act -> Interpret -> Return -> Reconsider`

A viewer should see at least three different kinds of action before the first minute ends.

The sequence should not read as twelve cutscenes.

## Youth engagement target

The cut moves forward only when most youth reviewers can state:

- What Mara was trying to accomplish.
- At least two actions she could take.
- One practical or social consequence.
- One character they want to understand better.
- One place they want to explore.
- One unresolved question.

Use `docs/research/YOUTH_ENGAGEMENT_TARGET_LOOP.md` and `docs/research/youth-playtest-scorecard.csv` for scoring.
