# Public Repository Boundary

## Purpose

This page defines which project material can enter the public repository.

## Allowed material

The repository can contain:

- Project-original design documentation.
- Original fictional names, dialogue, mechanics, and mission structures.
- Concise chapter references and source notes.
- Transformation records and review guardrails.
- Generated project graphics that pass rights review.
- Small canonical artifacts that fit the repository storage policy.

## Restricted material

Keep these items outside the public repository:

- The uploaded memoir PDF.
- Scans or photographs of book pages.
- Audiobook files.
- Publisher cover art.
- Long source quotations.
- Unlicensed music or performance recordings.
- Personal research records that contain private information.

## Large artifacts

Use Git Large File Storage, release assets, or approved project storage for large design binaries.

Commit a checksum and package record when the binary remains outside Git history.

## Review rule

A public artifact must pass source-fidelity and rights review before publication.
