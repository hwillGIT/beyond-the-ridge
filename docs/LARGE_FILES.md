# Large Files

## Current boundary

The opening storyboard source deck is close to the GitHub file-size limit.

Do not add more embedded media to that file without reducing its size.

## Storage rule

Use one of these methods for a larger binary artifact:

1. Reduce duplicate media inside the source file.
2. Store the editable file with Git Large File Storage.
3. Store the file as a release asset.
4. Store the file in approved project storage and commit a checksum record.

## Canon rule

Do not replace an editable source with only a PDF.

A PDF supports review. It does not support complete design editing.

## History rule

Do not commit repeated copies of a large deck under different names.

Update the canonical source and use releases for approved snapshots.
